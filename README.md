# PROYECTO-FINAL-WEB

La plataforma denominada My Teacher, está diseñada bajo el modelo de software como servicio (SaaS). Su objetivo principal es conectar a estudiantes con profesores particulares de manera eficiente. Cuenta con una interfaz completamente adaptable (responsive), lo que garantiza una experiencia de usuario óptima tanto en computadoras de escritorio como en dispositivos móviles.

Funcionalidades Principales
Sistema de Comunicación Directa:

Incorpora un chat en tiempo real que permite a los estudiantes resolver dudas rápidas, coordinar horarios y mantener contacto fluido con sus profesores antes y después de las clases.

Gestión de Sesiones y Material Didáctico:

Los profesores pueden cargar recursos adicionales para las clases.

El material de estudio descargable permanece bloqueado por seguridad y se libera de forma automática únicamente cuando se confirma la programación o realización de la sesión de tutoría.

Módulo de Pagos Integrado:

Cuenta con un flujo de pago simulado que emula la conexión con una API bancaria. Esto permite validar la experiencia de usuario en la contratación del servicio sin realizar transacciones reales.

Herramientas de Geolocalización:

Integra un mapa interactivo para aquellos casos en los que la tutoría se acuerde de forma presencial, facilitando la visualización del punto de encuentro y el cálculo de rutas.

Perfiles y Acceso de Prueba
La plataforma divide la experiencia según el rol del usuario (Estudiante o Docente) con perfiles completamente editables (foto, descripción, materias, tarifas).

Para facilitar el desarrollo y las demostraciones, el sistema incluye credenciales preconfiguradas, lo que permite iniciar sesión de manera instantánea en cualquiera de los dos roles para probar los flujos de interacción mutua (como el envío de mensajes o la reserva de clases) sin necesidad de registrar cuentas nuevas desde cero.
